# TGS-2025053922 - Certified Lean Six Sigma Yellow Belt (CLSSYB) Training

> Course: Certified Lean Six Sigma Yellow Belt (CLSSYB) Training  
> Course Code: TGS-2025053922

Hands-on Certified Lean Six Sigma Yellow Belt labs for learners supporting improvement projects and applying practical Lean Six Sigma tools. The labs cover Lean Six Sigma fundamentals, DMAIC, process mapping, facilitation, KPIs, data collection, run charts, Pareto analysis, root cause analysis, FMEA, Kaizen, 5S, mistake proofing, standard work, and control planning.

## How to Use

1. Open the learner guide first and review the Yellow Belt role and DMAIC flow.
2. Complete the labs in order because each lab builds part of a small improvement project.
3. Use a simple workplace process where possible.
4. Keep every artifact for the final A3-style improvement summary.
5. Use Excel, LibreOffice Calc, Google Sheets, paper, or diagrams.net as preferred by your trainer.
