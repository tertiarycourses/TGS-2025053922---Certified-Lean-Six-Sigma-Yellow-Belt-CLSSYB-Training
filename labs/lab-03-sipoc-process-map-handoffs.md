# Lab 3 - SIPOC, Process Mapping, Handoffs, and Yellow Belt SME Support

## Objective

Create a SIPOC and process map that helps an improvement team understand boundaries, handoffs, inputs, outputs, and customers.

## Scenario

The service desk manager asks you to map the ticket assignment process so a Green Belt can decide whether a larger DMAIC project is needed.

## Tasks

### Step 1 - Build SIPOC

Create:

| Suppliers | Inputs | Process | Outputs | Customers |
|-----------|--------|---------|---------|-----------|

Keep process steps high level: five to seven steps.

### Step 2 - Create detailed process map

Map each step:

| Step | Actor | Activity | System | Handoff |
|------|-------|----------|--------|---------|

### Step 3 - Mark pain points

On the process map, identify:

- Waiting points
- Rework loops
- Missing decision rules
- Duplicate entry
- Unclear ownership

### Step 4 - Prepare SME notes

Write notes a Yellow Belt SME would bring to a project team:

- What actually happens
- Where work gets stuck
- Which rules are informal
- Which data fields are unreliable
- Which people should be interviewed

## Deliverable

Submit SIPOC, detailed process map, pain point notes, and SME notes.

## Checkpoint questions

1. Why is SIPOC useful before detailed mapping?
2. What is a handoff risk?
3. How can a Yellow Belt help a project leader without owning the whole project?
