# Lab 04 - KPIs, Data Collection, and Visuals

## Objectives

- Define a KPI.
- Create a data collection plan.
- Build a run chart.
- Build a Pareto chart.

## Scenario

The team needs baseline evidence. You will define what to measure, collect or use sample data, and visualize the process issue.

## Steps

1. Select one primary KPI for the project.
2. Write an operational definition for the KPI.
3. Define unit, defect, opportunity, target, and data source where applicable.
4. Create a data collection plan with owner, method, frequency, and sample size.
5. Collect baseline data or use a trainer-provided dataset.
6. Check for missing values and inconsistent categories.
7. Create a run chart showing performance over time.
8. Add notes for known process changes or events.
9. Create a Pareto chart for issue categories.
10. Identify the largest contributor.
11. Write a focus statement for root cause analysis.

## Validation

- KPI definition is clear and measurable.
- Data collection method is practical.
- Run chart uses time order.
- Pareto chart is sorted from largest to smallest.

## Deliverables

- KPI definition.
- Data collection plan.
- Clean baseline data table.
- Run chart.
- Pareto chart.
- Focus statement.

## Review Questions

1. Why do KPIs need operational definitions?
2. What does a run chart reveal?
3. Why does Pareto analysis help teams focus?
4. What data quality checks should be done first?
