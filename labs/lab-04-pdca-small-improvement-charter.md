# Lab 4 - PDCA Small Improvement Project Charter

## Objective

Create a PDCA charter for a small improvement that a Yellow Belt could support or run under guidance.

## Scenario

The service desk wants to test whether a new ticket triage checklist reduces assignment delay within two weeks.

## Tasks

### Step 1 - Define PDCA cycle

Create a table:

| PDCA phase | Action for this scenario |
|------------|--------------------------|
| Plan | |
| Do | |
| Check | |
| Act | |

### Step 2 - Write problem and goal statements

Use this format:

```text
Problem: From <date range>, <process> experienced <measurable issue>, causing <customer/business impact>.
Goal: Reduce/increase <metric> from <baseline> to <target> by <date>.
```

### Step 3 - Define scope

Create:

| In scope | Out of scope |
|----------|--------------|

### Step 4 - Identify risks and assumptions

Create:

| Risk or assumption | Impact | Response |
|--------------------|--------|----------|

### Step 5 - Plan the test

Define:

- Test change
- Pilot team
- Start and end date
- Data to collect
- Review meeting
- Decision rule to adopt, adapt, or abandon

## Deliverable

Submit PDCA table, problem statement, goal statement, scope, risk table, and test plan.

## Checkpoint questions

1. Why is PDCA suitable for small improvements?
2. What makes a goal statement measurable?
3. What decision will you make after the Check phase?
