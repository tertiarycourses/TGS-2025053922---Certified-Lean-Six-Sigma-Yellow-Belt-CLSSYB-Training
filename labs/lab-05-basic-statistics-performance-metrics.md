# Lab 05 - Basic Statistics and Performance Metrics

## Objectives

- Calculate basic statistics.
- Interpret process variation.
- Calculate simple defect metrics.
- Summarize baseline performance.

## Scenario

Charts show patterns, but the team also needs simple numbers to describe performance. You will summarize center, spread, and defect performance.

## Steps

1. Open the baseline dataset from Lab 04.
2. Calculate count, mean, median, minimum, maximum, range, and standard deviation.
3. Create a histogram if the data is continuous.
4. Identify any obvious outliers.
5. Calculate yield if good units and total units are known.
6. Calculate DPU if defects and units are known.
7. Calculate DPMO if opportunities are known.
8. Compare actual performance with target.
9. Write a short baseline summary using numbers and plain language.
10. Identify one question that still needs investigation.

## Validation

- Calculations use the correct dataset.
- Variation is discussed, not only the average.
- Defect metrics use correct denominators.
- Baseline summary is understandable to a non-statistical reader.

## Deliverables

- Basic statistics table.
- Histogram if applicable.
- Yield, DPU, or DPMO worksheet.
- Baseline performance summary.

## Review Questions

1. Why can averages hide problems?
2. What is the difference between defects and defective units?
3. Why does DPMO include opportunities?
4. How does variation affect customer experience?
