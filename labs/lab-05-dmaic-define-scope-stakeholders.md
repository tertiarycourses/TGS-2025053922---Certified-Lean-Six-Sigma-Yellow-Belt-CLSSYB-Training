# Lab 5 - DMAIC Overview, Problem Statement, Scope, and Stakeholders

## Objective

Support the Define phase of a DMAIC project by clarifying the problem, scope, stakeholders, customers, and expected benefits.

## Scenario

The PDCA pilot shows promise, but management may escalate the issue to a larger DMAIC project. Your Yellow Belt task is to prepare clear Define information.

## Tasks

### Step 1 - Summarize DMAIC

Create:

| Phase | Purpose | Yellow Belt support |
|-------|---------|---------------------|
| Define | | |
| Measure | | |
| Analyze | | |
| Improve | | |
| Control | | |

### Step 2 - Refine problem statement

Check that your statement includes:

- Process
- Time period
- Measurable problem
- Impact
- No assumed root cause
- No assumed solution

### Step 3 - Identify stakeholders

Create:

| Stakeholder | Role | Interest | Communication need |
|-------------|------|----------|--------------------|

### Step 4 - Define project boundaries

Document:

- Start point
- End point
- Included departments
- Excluded departments
- Key assumptions

### Step 5 - Estimate benefit

Create benefit notes for:

- Time saved
- Defects reduced
- Waiting reduced
- Customer satisfaction improved
- Staff frustration reduced

## Deliverable

Submit DMAIC summary, refined problem statement, stakeholder table, project boundaries, and benefit notes.

## Checkpoint questions

1. Why should a problem statement avoid naming a solution?
2. Which DMAIC phases can a Yellow Belt support strongly?
3. Who must be involved before scope is finalized?
