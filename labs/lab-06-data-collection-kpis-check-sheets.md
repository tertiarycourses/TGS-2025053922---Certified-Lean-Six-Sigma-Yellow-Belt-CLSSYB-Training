# Lab 6 - Data Collection, KPIs, Check Sheets, and Basic Metrics

## Objective

Create a data collection plan with KPIs, operational definitions, check sheets, and basic metric calculations.

## Scenario

The service desk team has anecdotal complaints, but improvement decisions need data. You will design a simple measurement plan.

## Tasks

### Step 1 - Define KPIs

Create:

| KPI | Operational definition | Data source | Frequency |
|-----|------------------------|-------------|-----------|

Include assignment time, first response time, reopen rate, backlog, and customer status follow-up count.

### Step 2 - Create a check sheet

Design a check sheet with:

- Date
- Ticket ID
- Ticket type
- Assignment time
- Defect category
- Rework required
- Notes

### Step 3 - Define defect categories

Create categories:

- Missing information
- Wrong queue
- Delayed assignment
- Duplicate ticket
- Reopened ticket
- Unclear status

### Step 4 - Plan sampling

Document:

- Sample size
- Collection period
- Who records data
- How data is checked
- What bias might occur

### Step 5 - Calculate basic metrics

Use sample values to calculate:

- Total tickets
- Defect count
- Defect rate
- Average assignment time
- Range of assignment time

## Deliverable

Submit KPI table, check sheet, defect categories, sampling plan, and basic metric calculations.

## Checkpoint questions

1. Why does an operational definition matter?
2. What bias could affect your data?
3. Which KPI best reflects the customer pain point?
