# Lab 07 - Countermeasures, 5S, Poka-Yoke, and Standard Work

## Objectives

- Select countermeasures linked to causes.
- Apply 5S.
- Design mistake proofing.
- Draft standard work.

## Scenario

The team is ready to test improvements. You will choose countermeasures that are linked to evidence and easy to test safely.

## Steps

1. List supported root causes and high-priority FMEA risks.
2. Brainstorm possible countermeasures.
3. Remove ideas that do not address a supported cause or risk.
4. Use an impact-effort matrix to prioritize options.
5. Select one or two countermeasures for a small test.
6. Apply 5S to the relevant workspace, folder, form, or queue.
7. Identify one visual control such as a checklist, label, color code, or status board.
8. Design one poka-yoke idea to prevent or detect errors earlier.
9. Draft standard work for the improved process step.
10. Define test duration, success measure, and rollback condition.

## Validation

- Countermeasures link to root causes or risks.
- Impact-effort matrix supports the selection.
- Standard work is clear enough for another person to follow.
- Test criteria are measurable.

## Deliverables

- Countermeasure list.
- Impact-effort matrix.
- 5S action list.
- Visual control idea.
- Poka-yoke idea.
- Draft standard work.
- Test plan.

## Review Questions

1. Why should solutions connect to causes?
2. How does 5S help stabilize work?
3. What is mistake proofing?
4. Why is a small test safer than a full rollout?
