# Lab 7 - Pareto, Run Charts, Variation, Yield, DPU, and DPMO

## Objective

Analyze simple process data using Pareto charts, run charts, variation concepts, yield, DPU, and DPMO.

## Scenario

You collected two weeks of service desk data. The team wants to know which defect category matters most and whether assignment time is improving.

## Tasks

### Step 1 - Build Pareto table

Create:

| Defect category | Count | Percent | Cumulative percent |
|-----------------|-------|---------|--------------------|

Sort categories from highest to lowest count.

### Step 2 - Create Pareto chart

Using spreadsheet software:

1. Enter defect categories and counts.
2. Sort descending.
3. Add cumulative percent.
4. Create bar chart for counts.
5. Add cumulative percent line if your tool supports it.

### Step 3 - Create run chart

Create a run chart of daily average assignment time.

Record:

- Baseline average
- Highest point
- Lowest point
- Direction of trend
- Any unusual point

### Step 4 - Calculate yield, DPU, and DPMO

Use:

```text
Yield = Good Units / Total Units
DPU = Defects / Units
DPMO = (Defects / (Units * Opportunities per Unit)) * 1000000
```

### Step 5 - Interpret variation

Write notes:

- What variation is normal?
- What variation needs investigation?
- What data is missing?
- What conclusion should not be made yet?

## Deliverable

Submit Pareto table, chart screenshot or notes, run chart, metric calculations, and interpretation notes.

## Checkpoint questions

1. What does a Pareto chart help prioritize?
2. What does a run chart show over time?
3. Why should you avoid overreacting to one data point?
