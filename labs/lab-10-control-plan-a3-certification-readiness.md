# Lab 10 - Control Plan, A3 Summary, Handover, and Certification Readiness

## Objective

Create a control plan, A3-style improvement summary, handover checklist, and personal certification readiness plan.

## Scenario

The PDCA test improved assignment time. The team needs a simple control plan so the gain is sustained and management can decide whether to expand the solution.

## Tasks

### Step 1 - Create control plan

Create:

| Process step | Metric | Target | Owner | Check frequency | Response plan |
|--------------|--------|--------|-------|-----------------|---------------|

### Step 2 - Define visual management

Choose simple visuals:

- Weekly run chart
- Defect category Pareto
- Status board
- Checklist compliance count
- Escalation trigger list

### Step 3 - Write A3 summary

Create sections:

1. Background
2. Current condition
3. Goal
4. Analysis
5. Countermeasures
6. Implementation plan
7. Results
8. Follow-up and control

### Step 4 - Prepare handover

Create handover checklist:

- Process owner accepts control plan.
- Standard work is stored.
- KPI report owner is assigned.
- Review cadence is scheduled.
- Open issues are listed.
- Escalation criteria are documented.

### Step 5 - Build certification readiness plan

Create:

| Topic | Confidence 1-5 | Evidence from labs | Next review action |
|-------|----------------|--------------------|-------------------|

Include Lean, Six Sigma, PDCA, DMAIC, process mapping, data, root cause, improve tools, and control.

## Deliverable

Submit control plan, visual management notes, A3 summary, handover checklist, and certification readiness plan.

## Checkpoint questions

1. Why does an improvement need a control plan?
2. What should happen if a metric falls outside target?
3. Which Yellow Belt topic needs your most review?
