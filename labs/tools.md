## Spreadsheet formulas

```text
Yield = Good Units / Total Units
DPU = Defects / Units
DPMO = (Defects / (Units * Opportunities per Unit)) * 1000000
Percent = Count / Total Count
Cumulative Percent = Running Total / Total Count
```
